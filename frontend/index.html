O sistema em números

NF-e

NCM · CFOP · CSOSN

Sugestão de classificação de produtos por busca textual e semântica, com motor de regras.

NFS-e

CNAE · LC 116 · NBS

Caminho de classificação para serviços, com bases públicas importadas.

DAS

Simples Nacional

Calculadora de alíquota efetiva e do DAS (Anexos I a V).

Arquitetura dos contêineres

01 · Frontend

Nginx + HTML/CSS/JS

Serve esta interface na porta 80 e encaminha /api para o backend.

02 · Backend

Node.js + Express

API REST com o CRUD das seções e a conexão com o PostgreSQL.

03 · Banco

PostgreSQL 16

Guarda os dados em um volume Docker, que persiste mesmo se o contêiner for recriado.
